# Write Memo

Turn an exploration into a tight, decision-ready memo.

## Structure

- Lead with the recommendation or conclusion, not the background.
- Follow with the key evidence/reasoning that supports it, concisely.
- Note the main alternative considered and why it lost.
- Keep it short — a memo that takes longer to read than the decision deserves has failed its purpose.
