# Compare Table

Emit a structured side-by-side comparison as the final artifact of an exploration.

## How to execute

- Columns = the options compared; rows = the dimensions that actually mattered during the exploration (not a generic template).
- Fill cells with specifics (numbers, concrete facts), not adjectives.
- Leave a cell blank rather than inventing a figure you don't actually know.
