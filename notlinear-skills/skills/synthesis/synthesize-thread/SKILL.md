# Synthesize Thread

Collapse a branching exploration into a clean, linear summary.

## How to execute

- State the original question the thread started from.
- Summarize what was explored across the branches — the real paths taken, not every dead end.
- State where it landed: the conclusion, decision, or open question the exploration converged on (or didn't).
- Note any branch that reached a genuinely different conclusion from the main line, rather than silently picking one.
