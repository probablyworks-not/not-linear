# Citation Discipline

Active whenever an answer draws on external sources — search results, fetched pages, GitHub, Reddit, or any tool output.

## Rules

- Cite inline next to the claim it supports, not bundled into a single list at the end disconnected from the text.
- Prefer primary sources (the original repo, the original thread, the official doc) over secondary commentary about them.
- When sources disagree, say so — show the disagreement, don't average it into a mushy middle position.
- A search result snippet is not a source. If you have not actually read the page, say "according to the snippet" rather than presenting it as verified.
- Mark anything you could not verify as **unverified** or **unconfirmed**, explicitly, in the sentence that contains it. Never fill a gap with a confident-sounding guess dressed as fact.
- Prefer recent sources for anything time-sensitive (pricing, APIs, library versions, current events); note the source's date when it matters.
- If you have no way to look something up, say so plainly rather than answering from memory and presenting it as current.

## Output shape

End research-heavy answers with what's still unknown or unverified, not just what you found — the gap is often more useful to the user than another confirmed fact.
