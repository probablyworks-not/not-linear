# Opportunity Sizing

Rough-size an opportunity, including its opportunity cost.

## How to execute

- Estimate rough reach (how many people/how often this problem occurs) using available data or stated, labeled assumptions — never present a guess as a researched figure.
- Estimate the impact per instance (time saved, revenue, retention effect).
- Name explicitly what doing this costs in terms of what else doesn't get built — sizing an opportunity without this is incomplete.
