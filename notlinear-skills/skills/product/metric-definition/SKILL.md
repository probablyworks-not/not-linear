# Metric Definition

Define a metric precisely enough to actually use, plus its counter-metric.

## How to execute

- State the exact definition (what counts, what doesn't, over what window) — vague metrics can't be acted on.
- Define the counter-metric that would catch the obvious way to game the primary one (e.g. engagement time without a counter-metric on satisfaction rewards dark patterns).
- State the target or threshold that would count as success, if one exists.
