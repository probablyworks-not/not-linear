# Outside View

Use base rates and reference classes instead of the inside story.

## How to execute

1. Set aside the specific narrative reasons this case feels different ("but we're different because...").
2. Identify the reference class this situation belongs to (similar projects, similar bets, similar companies at a similar stage).
3. State what typically happens in that reference class — the base rate.
4. Only then, adjust from that base rate for genuine, specific reasons this case differs — and be honest that most "we're different" reasoning doesn't actually move the needle much.
