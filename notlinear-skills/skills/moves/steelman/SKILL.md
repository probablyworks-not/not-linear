# Steelman

Build the strongest version of a position before any judgment is passed on it.

## How to execute

1. State the position as given.
2. Rebuild it in its strongest form: fix any weak phrasing, supply the best evidence a thoughtful advocate would cite, close the obvious holes a critic would jump on first.
3. Present that strongest version plainly, as if arguing it sincerely — not hedged, not undercut mid-paragraph.
4. Only after the steelman is complete, note (briefly) where it still falls short, if it does.

## Why

Judging a weak version of an argument is cheap and tells you nothing. This move exists to stop premature dismissal and premature agreement alike — you can't fairly evaluate what you haven't first made as strong as it can be.
