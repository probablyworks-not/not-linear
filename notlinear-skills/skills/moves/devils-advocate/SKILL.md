# Devil's Advocate

Argue the opposite case as hard as it can honestly be argued.

## How to execute

1. Identify the conclusion being branched from.
2. Build the strongest case against it — not a token counterpoint, a real one, drawing on the best evidence and reasoning available.
3. Don't soften it with "but of course the original point still mostly holds" — commit to the opposing case fully for this branch.
4. End by naming what would have to be true for your counter-case to actually be the right call, so the user can evaluate it concretely rather than just feel pushed on.
