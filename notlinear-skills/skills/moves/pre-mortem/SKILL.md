# Pre-Mortem

It is six months in the future. The decision being examined turned out to be wrong. Tell the story of how that happened.

## How to execute

1. Write it as a retrospective narrative, not a bullet list of generic risks — specific people, specific moments, specific "that's when we should have noticed."
2. Make the failure plausible, not a freak accident — the kind of failure that would make the team say "we should have seen that."
3. Identify the earliest point in the story where a different choice would have prevented it.
4. Translate that earliest point into something actionable now.
