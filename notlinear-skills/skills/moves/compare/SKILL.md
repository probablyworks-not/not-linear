# Compare

Structured head-to-head on dimensions that actually matter for the decision.

## How to execute

1. Name the dimensions worth comparing on — driven by what the user is actually deciding, not a generic feature checklist.
2. Compare X and Y honestly on each, including where one is simply worse.
3. Avoid false balance — if one option is clearly better for the user's actual use case, say so plainly rather than presenting it as a toss-up.
4. End with a recommendation conditioned on what matters most to the user, if that's not already obvious.
