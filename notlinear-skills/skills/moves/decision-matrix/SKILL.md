# Decision Matrix

Structured options-vs-criteria comparison that ends in a call.

## How to execute

1. List the real options (not a strawman option included just to be rejected).
2. List the criteria that actually matter for this decision — not a generic checklist.
3. Score each option against each criterion honestly, including where an option is weak.
4. State a recommendation explicitly. The matrix is a tool to reach a call, not a way to avoid making one.
