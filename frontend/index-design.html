Non-linear chat for research

Alex Chen
14 min read
2 branches

A canvas for non-linear thinking. The premise: most tools force a single thread, but real thinking forks constantly.

The problem

Linear chat conflates two distinct activities: composing a coherent argument and exploring the space around it.

Core flows

1. Select → Branch

Highlight any text to start a side-branch with AI.

2. Branch the branch

Inside any branch panel, you can highlight an AI reply and branch again.

3. The composer is always there

Below this doc is a chat composer. Type into it to keep talking to AI without picking a sentence.
