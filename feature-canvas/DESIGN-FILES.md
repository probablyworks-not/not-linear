# Separate design files

- Conversations.dc.html — conversation canvas; current active design.
- Agents.dc.html — agent canvas and expanded agent details.

Each HTML file is an independent editable design. Shared assets: support.js, ds-base.js and the parent design system. Agents also uses agent-workspace.js and agent-workspace.css.

ThinkingCanvas.dc.html preserves the combined design as a reference.
