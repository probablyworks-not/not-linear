# not-linear
this is not-linear a not linear chat based system for research

## Desktop web app

Double-click `Notlinear.app` on your Desktop to run the MVP desktop app.
It opens Notlinear in its own macOS window, not in your browser.

The desktop app starts a small local server at `http://127.0.0.1:8765/notlinear.html` behind the scenes.
You do not need to open that URL yourself.

When you edit `notlinear.html`, the running app checks for changes every few seconds.
If it sees a newer file, click **New update - refresh** in the bottom-right corner.

Chats are saved in your browser for that local address. Keep using the same browser/profile and avoid clearing site data if you want chats to remain available.
