GET SET UP

Three steps.
Then follow your curiosity.

  1. Download and install.

    Open the DMG and drag Notlinear into Applications.

  2. Approve the first launch.

    This free beta is not notarized by Apple. Try opening it once. If macOS blocks it, go to System Settings → Privacy & Security → Open Anyway, where available, if you trust this download. Managed Macs may restrict this.

    Read Apple’s opening instructions ↗
  3. Add your API key.

    Open Settings, enter a supported provider’s key, and start a conversation. Model usage is billed by your provider.

Your workspace stays here.

Chats and Notes live on your Mac. Your configured AI and research services receive the content needed for your requests. No Notlinear account is required.

Keys currently use local browser storage. Keychain storage and a complete workspace backup are still being developed. Some app assets load from CDNs.

Updates, at your pace.

The app checks for new releases and offers a download when one is available. Finish your work, quit the app, and replace it using the new DMG. Updates do not install automatically.

Keep the same local address and avoid clearing website data. Only run one copy at a time.
