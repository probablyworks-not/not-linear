## 2026-10-04 — P2 complete: hardening + provider registry
- **(a) `X-Notlinear-Local` header.** A custom header cannot be sent cross-origin without a preflight, and the preflight only succeeds for a loopback origin — so this blocks a foreign page even on requests that would otherwise be "simple" and skip CORS. Added in `api-client.js` for same-origin URLs ONLY, deliberately not for provider APIs where it would cause a needless preflight and advertise the caller. `feedback.js` has its own `post()` wrapper and six raw `fetch` sites were patched individually. Asserted in a real browser as well as pytest: with the header 200, without it 403, and through the real `loggedFetch` wrapper 200 — so a missed call site fails a test.
- **(b) SSRF.** `services/safe_fetch.py`. Rejects if **any** resolved address is non-public (a host returning one public and one private address is a deliberate bypass), pins the connection to the validated IP with the hostname in `Host` so DNS cannot rebind between check and connect, and re-validates **every** redirect hop — validating only the first URL is the usual way these filters are defeated. Handles IPv4-mapped IPv6. The `{"ok": false, "error": ...}` contract is unchanged so `notes.js:976` is untouched.
- **(c) Consent ledger.** `~/.notlinear/allowed_roots.json`, written only by `pick_folder` — the dialog *is* the consent. Symlinks resolve before the prefix check. Upgrade path is trust-on-first-use on an empty ledger, because existing installs picked their folder before any ledger existed and would otherwise 403 on first scan. My first attempt at that migration had muddled precedence and would never have fired; caught by reading it back, not by a test.
- **(d) argv AppleScript.** `save_file` no longer interpolates the filename. A test asserts the payload appears in argv and *not* in the script source. Note the first version of that test used a payload containing `/`, which the filename validator rejected before `osascript` was ever reached — proving nothing; it needed a slash-free payload to actually exercise the argv path.
- **(P2b) Provider registry.** One `TOOL_SPECS` list; Anthropic schema, OpenAI schema and the system-prompt prose are all *derived*. Descriptions are prompt text and are copied verbatim, with a test asserting each still appears in `app.js` and that `app.js` defines no tool the registry lacks. That oracle has a lifetime — delete it in P5d.
- **Repeat offence worth naming:** the consent ledger was not in the autouse isolation fixture, so a test run wrote into the home directory. This is exactly BUGS.md #053, and the lesson ("any new module-level path goes into `isolated_paths` in the same change") was written down and then not applied. The fixture now covers it.
- Next: P3 — React shell, dev proxy, tokens-only theming.

## 2026-10-04 — P-1 correction: per-realm storage, not per-origin
- User reported the desktop app shows entirely different threads than the browser. Cause: `Notlinear.app` is a WKWebView using the default `WKWebsiteDataStore`, which is scoped to the app container (`~/Library/WebKit/local.notlinear.app/`), not shared with any browser.
