Restore notlinear data

Writes a backup file back into this browser profile's databases and localStorage.

This overwrites rows that share a key with the backup. Your chat history is a single row called state, so restoring replaces all threads, branches and highlights with the ones in the file. Rows the backup does not mention are left alone, and nothing is ever cleared wholesale — but if this profile has newer work than the file, restoring loses it. Export first if you are unsure.
